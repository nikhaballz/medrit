MEDRIT — Safari web app

Files: upload every file in this folder to the ROOT of your GitHub Pages repository.
Keep groot-hero.png with index.html; it is the main photo on the Stopwatches page.

To install on iPhone:
1. Open your published GitHub Pages HTTPS address in Safari.
2. Tap Share, then Add to Home Screen.
3. Launch MedRit from the Home Screen.

Your tracker records are stored in this browser on this device. They are not uploaded to GitHub. Do not clear Safari website data for the site unless you have a backup.

Important: starting a stopwatch immediately creates a medication entry and deducts stock. Only start one after the medication has actually been taken according to the prescriber's instructions. Stopping a stopwatch does not remove the medication entry.
